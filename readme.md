# AIと画像処理を活用した自律走行ロボット

## 1. プロジェクト概要

Physical AI 応用1の最終課題として、ROS 2とGazeboを使用した車型ロボットの自律走行システムを開発しました。

ロボット前方のカメラ画像から黄色のコースラインを検出し、その位置に応じて進行方向を制御します。また、AIモデルYOLO11nを導入し、カメラ画像から周囲の物体を認識する機能を組み込みました。

## 2. 開発環境

| 項目 | 使用技術 |
|---|---|
| OS | Windows 11 / WSL2 Ubuntu 22.04 |
| 実行環境 | Docker |
| ロボットシミュレータ | Gazebo |
| ロボットミドルウェア | ROS 2 Jazzy |
| プログラミング言語 | Python |
| 画像処理 | OpenCV / NumPy |
| AIモデル | YOLO11n |
| 深層学習フレームワーク | PyTorch |
| AI実行ライブラリ | Ultralytics |

## 3. 主な機能

### 3.1 黄色ラインによる自律走行

- カメラ画像からHSV色空間を利用して黄色ラインを抽出
- 画像を遠方・中間・手前の領域に分割
- ラインの位置からコース中央を推定
- コース中央からのずれに応じて旋回方向を制御
- ROS 2の `/cmd_vel` に速度指令を送信

### 3.2 YOLO11nによる物体検出

- 学習済みYOLO11nモデルを使用
- カメラ画像をリアルタイムに受信
- 画像内の物体を推論によって検出
- 検出結果を画像に描画して保存

### 3.3 AIと自律走行の統合

`auto_drive_yolo.py` では、YOLO11nによる人物検出と黄色ラインによる走行制御を統合しています。

人物を検出した場合は停止指令を送信し、検出しない場合は黄色ラインに沿って走行します。

## 4. プログラム構成

| ファイル | 内容 |
|---|---|
| `auto_drive_cv.py` | OpenCVによる黄色ライン検出と自律走行 |
| `auto_drive_yolo.py` | YOLO11nと自律走行制御を統合 |
| `yolo_camera.py` | カメラ画像を使用したYOLO11nの推論 |

## 5. 実行方法

ROS 2の環境を読み込み、Python仮想環境を有効にした状態で実行します。

### 黄色ラインによる自律走行

```bash
python /workspace/auto_drive_cv.py
```

### YOLO11nを統合した自律走行

```bash
python /workspace/auto_drive_yolo.py
```

### YOLO11nによるカメラ画像の物体検出

```bash
python /workspace/yolo_camera.py
```

※Gazebo、ROS 2のカメラ画像配信、および必要なROS 2トピックが動作している必要があります。

## 6. 必要なPythonライブラリ

以下の動作を確認しています。
