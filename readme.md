# AIと画像処理を活用した自律走行ロボット

## 1. プロジェクト概要

Physical AI 応用1の最終課題「AI×ロボティクスによる創造的タスクの実現」として、ROS 2とGazeboを使用した車型ロボットの自律走行システムを開発しました。

ロボット前方のカメラ画像を取得し、OpenCVによる画像処理で黄色のコースラインを検出します。検出したラインの位置からコース中央を推定し、そのずれに応じて進行方向を制御します。

さらに、物体認識AIモデルYOLO11nを導入し、カメラ画像から周囲の物体を検出する機能を組み込みました。最終的に、画像処理による走行制御とAIによる物体検出を統合したプログラムを作成しました。

## 3. システムの構成

本システムでは、Gazebo上の車型ロボットに搭載されたカメラ画像をROS 2経由で取得し、Pythonプログラムで処理します。

主な処理の流れは次のとおりです。

1. カメラ画像をROS 2トピック `/front_camera` から取得
2. OpenCVで黄色のコースラインを抽出
3. 画像内の複数の領域からライン位置を取得
4. コース中央からのずれを計算
5. ずれに応じた速度・旋回指令を生成
6. ROS 2トピック `/cmd_vel` に走行指令を送信

これに加えて、YOLO11nによる物体検出を行い、走行制御と組み合わせています。

## 4. 主な機能

### 4.1 OpenCVによる黄色ライン検出

- カメラ画像をHSV色空間に変換
- 黄色の範囲を指定してコースラインを抽出
- 画像を遠方・中間・手前の複数の領域に分割
- 各領域のライン位置からコース中央を推定
- コース中央からのずれに応じて旋回方向を制御
- `/cmd_vel` に速度・旋回指令を送信

画像の上部には建物などの背景が含まれるため、検出範囲を調整しました。画像の複数の領域を利用することで、ライン位置をもとにした走行制御を行っています。

### 4.2 YOLO11nによる物体検出

- 学習済みYOLO11nモデルを使用
- カメラ画像をリアルタイムに取得
- YOLO11nによる物体認識を実行
- 検出した物体の種類や位置を取得
- 検出結果を画像に描画して保存

カメラ画像をROS 2で受信する際には、センサーデータ用のQoS設定を使用しました。これにより、カメラ画像を受信してYOLO11nの推論を実行できることを確認しました。

### 4.3 YOLO11nと自律走行制御の統合

`auto_drive_yolo.py` では、YOLO11nによる物体検出とOpenCVによる黄色ライン検出を統合しています。

人物を検出した場合には停止指令を送信し、人物を検出しない場合には黄色ラインに沿って走行する処理を実装しています。

ただし、人物をGazebo上に配置して停止動作を確認する実験は未実施です。そのため、人物検出時の停止機能は実装段階であり、動作確認が今後の課題です。

## 5. Geminiを利用した画像分析

開発時には、カメラ画像をGeminiに提示し、コースラインと背景の見え方について分析しました。

その分析を参考に、建物などの背景がライン検出に混ざりにくいよう、画像処理で使用する領域（ROI）の位置を調整しました。

Geminiは開発時の画像分析・検討に使用したものであり、ロボットの走行中にGeminiが判断や制御を行う構成ではありません。

## 6. プログラム構成

| ファイル | 内容 |
|---|---|
| `auto_drive_cv.py` | OpenCVによる黄色ライン検出と自律走行 |
| `auto_drive_yolo.py` | YOLO11nによる物体検出と自律走行制御の統合 |
| `yolo_camera.py` | カメラ画像を使用したYOLO11nの推論確認 |

## 7. 実行方法

GazeboとROS 2を起動し、カメラ画像が `/front_camera` から配信されている状態で実行します。

ROS 2の環境を読み込み、Python仮想環境を有効にした状態で、以下のコマンドを実行します。

### 黄色ラインによる自律走行

```bash
python /workspace/auto_drive_cv.py
```

### YOLO11nを統合した自律走行

```bash
python /workspace/auto_drive_yolo.py
```

### YOLO11nによるカメラ画像の物体検出

```bash
python /workspace/yolo_camera.py
```

※Gazebo、ROS 2のカメラ画像配信、および必要なROS 2トピックが動作している必要があります。

## 8. 必要なPythonライブラリ・ファイル

- rclpy
- sensor_msgs
- geometry_msgs
- cv_bridge
- OpenCV
- NumPy
- PyTorch
- Ultralytics

また、YOLO11nの学習済みモデル `yolo11n.pt` が必要です。

このモデルファイルは本リポジトリには含めていないため、別途用意し、プログラムから参照できる場所に配置してください。

## 9. 動作確認結果

開発中に以下の動作を確認しました。

- Gazebo上での車型ロボットの走行
- ROS 2によるカメラ画像の受信
- OpenCVによる黄色ラインの抽出
- 黄色ラインの位置に基づく自律走行
- YOLO11nによる静止画像の物体検出
- YOLO11nによるカメラ画像のリアルタイム推論
- YOLO11nと走行制御を統合したプログラムでのGazebo上の走行

一方、左カーブでの安定した走行や、人物検出時の停止動作については、十分な動作確認ができていません。

## 11. まとめ

本プロジェクトでは、ROS 2とGazeboを用いたシミュレーション環境を構築し、カメラ画像を利用した自律走行に取り組みました。

OpenCVによるコースライン検出と走行制御に加え、YOLO11nによる物体検出を導入し、それらを統合したプログラムを作成しました。

環境構築、カメラ画像の取得、画像処理、AIモデルの導入、走行制御との統合を段階的に進め、実際にGazebo上で自律走行することを確認しました。

今後は、カーブや交差点への対応、人物・障害物の検出と回避など、より複雑な環境で安定して走行できるシステムへの発展を目指します。
